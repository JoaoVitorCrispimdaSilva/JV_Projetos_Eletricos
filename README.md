# JV Projetos Elétricos

Landing page desenvolvida para divulgação de serviços de engenharia elétrica.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Menu responsivo
- Animações ao rolar página
- Formulário de orçamento
- Integração com WhatsApp
- Seção de serviços
- FAQ

## Estrutura

/index.html
/css/style.css
/js/script.js
/img/

## Como editar

Alterar textos:
- index.html

Alterar cores:
- css/style.css

Alterar interações:
- js/script.js

Alterar imagens:
- pasta img
